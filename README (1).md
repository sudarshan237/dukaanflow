# DukaanFlow

An interactive front-end prototype for lightweight enquiry management for small businesses.

## Run locally
Open `index.html` in a modern browser. No build process or dependencies are required.

## Prototype scope
- Sample enquiry inbox with search and status filters
- Simulated local intent classification and editable response drafts
- Product catalogue concept
- Local status updates and follow-up affordance

## Current limitations
This is a front-end concept prototype using sample data. It does not yet include a backend, persistent storage, a live LLM, authentication, or WhatsApp/Instagram integrations. Suggested replies are simulated with local rules. Do not enter real customer information.
